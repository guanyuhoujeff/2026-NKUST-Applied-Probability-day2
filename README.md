# 應用機率・第二天：非監督式學習互動系統

高科大風險管理與保險系「應用機率」協同教學第二天的課堂互動系統。主題是非監督式學習：建模時不看違約答案，看能不能找出規律。

全天用第一天同一份資料（Kaggle「Give Me Some Credit」）、同一批學生資料（2,000 人，違約 134 人），分三段。每一段都由老師頁切步，學生手機跟著跳。

1. **PCA**（四步）：2 欄（額度使用率 × 年齡）壓到一條線上 → 10 欄壓成 k 個分數，看還原得回來幾成 → 看權重替 PC1、PC2 取名 → 投票「違約的人會集中在哪裡」，揭曉各主成分高分端的違約比例。
2. **分群**（三步）：全班看同一份分群（10 欄、GMM、3 群）→ 看每群的長相，投票哪一群最會違約 → 揭曉。揭曉後學生可以「自己試」：換欄位、群數（2–8）、方法（GMM 或 K-means），拼鑑別度。
3. **異常偵測**（三步，比賽）：講規則、先投票 → 抓異常 → 揭曉排行榜。學生有四條路線：
   - 只挑欄位：最少見的 10% 是異常
   - 挑欄位 → PCA（留幾個分數）：最少見的 10% 是異常
   - 挑欄位 → 分群：人數最少的那一群是異常（電腦挑）
   - 挑欄位 → PCA → 分群：同上

技術：FastAPI + Vue 3 + WebSocket。學生端是手機版，老師端是大螢幕。3D 圖用 canvas 自己畫，不需要外部網路。狀態都在記憶體裡，伺服器重啟就清空。

## 前處理（三段共用，`backend/prep.py`）

切法跟第一天同一行程式：學生 2,000 人，其餘 148,000 人當考題。下列參數只用學生 2,000 人算：

1. 三個逾期欄的 96、98 當缺值。這是資料代碼，不是次數；全部有 269 人，學生資料裡 6 人。
2. 缺值補中位數。
3. 固定 7 欄取 log：額度使用率、三個逾期欄、負債比、月收入、房貸筆數。
4. 標準化。

## 分數：鑑別度

分群「自己試」和抓異常比賽用同一把尺（`cluster_seg.spread_score`）：分出來的群，能不能把會違約和不會違約的人分開。

- 算法：Σ（人數 ≥ 20 的群）人數 ×（該群違約比例 − 全體比例）² ÷（總人數 × 全體比例 ×（1 − 全體比例））× 100。每群都差不多是 0 分；有一群全是違約的人、其他群都沒有是 100 分。
- 少於 20 人的群不算，人太少不準。
- 群數越多，分數通常越高（切得越細，各群的比例越容易拉開）。
- 抓異常：把人分成「異常／正常」兩群來算。學生手機只看自己 2,000 人的分數；排行榜用考題 148,000 人的分數，揭曉才看得到，同分並列。
- 建模全程不看違約答案；答案只用來算分。

**揭露**
- 「最少見的 10%」的 10% 是看過答案才定的。
- 抽樣種子 4 同第一天，是從 20 份隨機抽樣中挑出最能示範的一份。

## 畫面上的主要數字（`backend/tests/` 有驗證）

**PCA**
- 「留下幾成資訊」：1 個分數 19%、3 個 49%、5 個 68%。
- 2 欄示範：額度使用率 × 年齡（相關 −0.29），壓成 1 個分數留下 65%。
- 若 96/98 保留原樣，PC1 從 19% 變 25%。
- 揭曉（學生資料 2,000 人，全部違約 6.7%）：分數最高的 10% 人違約比例 PC1 32.5%、PC2 15.5%、PC3 15.5%。

**分群**（全班那一份：10 欄、GMM、3 群）

| 群 | 學生資料人數 | 考題違約比例 |
|---|---|---|
| 第 1 群 | 1,301 | 2.7% |
| 第 2 群 | 528 | 7.1% |
| 第 3 群 | 171 | 33.5% |

**異常偵測**
- 只挑欄位（不做 PCA、不分群）時，每種欄位數最高的考題鑑別度：1 欄 5.5、3 欄 12.9、10 欄 8.3。欄位不是越多越好。
- 違約的人裡，32.6% 過去從沒逾期過（異常≠會違約）。

## 啟動

```bash
cd backend
pip install -r requirements.txt
python download_data.py
python -m pytest -q tests
cd ../frontend && npm install && npm run build
cd ../backend && python server.py        # http://localhost:52014
```

- 學生：`http://<主機>:52014/`
- 老師：`http://<主機>:52014/teacher.html`
- 測試請另開埠，例如 `python -m uvicorn server:app --port 52099`，不要在上課用的埠上按揭曉或清除。
- 老師頁預設沒有密碼。要加：設環境變數 `DAY2_TEACHER_KEY`，或放一個 `backend/teacher_key.txt`（不進 repo），再重啟。

## 老師頁

- 最上面的紅框「提示」：告訴老師學生現在看到什麼、接下來按哪一顆。照著按就能走完一堂課。
- **① PCA／② 分群／③ 異常偵測**：學生手機跟著換段落，投票也跳到那一段的題目。
- **④ 截止提交**：抓異常不再收提交。截止後再按 ③，會先問要不要重新開放。
- **揭曉答案**（投票卡上）：PCA、分群一次做完三件事：投票答案、公布誰違約、這一段的違約比例。上方的「公布誰違約」「揭曉：某段」在答案還沒揭曉時也是同一套。
- 答案揭曉過（或露出來過）的題目不能再投，收起答案也一樣。
- **揭曉：異常偵測**：排行榜、欄位數曲線、「異常≠會違約」的案例；之後再揭曉投票答案。
- **清除**：清掉全部投票、取名、提交，回到 PCA 第 1 步。
- 學生手機會記住暱稱；重新整理後，投過的票和交過的那一組會回來。
